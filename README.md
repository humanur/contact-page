# Accessible Contact Page

A small single-page contact page built with plain HTML, CSS and JavaScript. I made it to practice responsive layout, semantic HTML and accessible forms. The on-screen texts are in Turkish.

## How to run

1. Download or clone this folder.
2. Open `index.html` in your browser.

Optional: open the folder in VS Code and use the Live Server extension to reload automatically.

## What it does

- Looks good on both phone and computer
- A menu button that opens and closes the menu
- A contact form where every field has a label
- Shows an error message when the input is wrong
- Can be used with the keyboard

## Limitations

The form does not send data anywhere. It only checks the input and shows a confirmation message.
